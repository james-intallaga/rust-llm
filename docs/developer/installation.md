# Installation

Forge SDK supports iOS, macOS, and Android. Choose your platform below.

---

## iOS / macOS (ForgeSwift)

ForgeSwift is distributed as a Swift Package with a Rust core via XCFramework.

### Step 1: Build the Native Frameworks

Pre-built Apple binaries are intentionally not stored in Git. Build reproducible
local frameworks before adding the Swift package:

```bash
git submodule update --init --recursive
./scripts/build-apple.sh
```

This creates `llama.xcframework` and `ForgeSwift/ForgeRustCore.xcframework`.

### Step 2: Add the Package

#### Option A: Xcode GUI

1. Open your project in Xcode 15+
2. Go to **File** → **Add Package Dependencies...**
3. Click **Add Local...** (bottom-left)
4. Select the `ForgeSwift` folder
5. Choose the `ForgeSwift` library for your target(s)

#### Option B: Package.swift

```swift
// Package.swift
let package = Package(
    name: "YourApp",
    platforms: [.iOS(.v15), .macOS(.v13)],
    dependencies: [
        .package(path: "../path/to/ForgeSwift")
    ],
    targets: [
        .executableTarget(
            name: "YourApp",
            dependencies: [
                .product(name: "ForgeSwift", package: "ForgeSwift")
            ]
        )
    ]
)
```

### Step 3: Prerequisites

The SDK requires:
- A locally built `llama.xcframework` in the repository root
- A locally built `ForgeRustCore.xcframework` in `ForgeSwift/`

Both are generated by `./scripts/build-apple.sh` and ignored by Git.

### Step 4: Initialize

```swift
import ForgeSwift

// Initialize Forge backend (call once at app start)
initializeForge()

// Create engine with auto-configured settings
let engine = try ForgeEngine(modelPath: "/path/to/model.gguf", config: .auto())
```

## Android (ForgeAndroid)

ForgeAndroid is an Android library module with a JNI bridge to the Rust core.

### Step 1: Build Native Libraries

Before building, you need to compile the native libraries for Android:

```bash
# Install prerequisites (one-time)
rustup target add aarch64-linux-android x86_64-linux-android
cargo install cargo-ndk

# Build native libraries
cd forge-rust
./scripts/build-android.sh
```

This builds:
- `libllama.so` and GGML libraries for Android
- `libforge_core.so` (Rust core)

### Step 2: Add the Module

#### Option A: Include in your project

1. Copy the `ForgeAndroid/forge-android/` folder to your project
2. Add to your `settings.gradle.kts`:

```kotlin
include(":forge-android")
project(":forge-android").projectDir = file("path/to/forge-android")
```

3. Add dependency in your app's `build.gradle.kts`:

```kotlin
dependencies {
    implementation(project(":forge-android"))
}
```

#### Option B: Use the example project

Open `ForgeAndroid/` in Android Studio and run the example app.

### Step 3: Configure NDK

Create `local.properties` in your project root:

```properties
sdk.dir=/path/to/Android/sdk
```

And ensure your `build.gradle.kts` sets the NDK version:

```kotlin
android {
    ndkVersion = "27.0.12077973"
}
```

### Step 4: Initialize

```kotlin
import com.forge.sdk.*

// Create engine with auto-configured settings
val config = ForgeConfiguration.auto(context)
val engine = ForgeEngine.create(modelPath, config)

// Don't forget to close when done
engine.close()
```

## Adding Models

### iOS

- **macOS**: Any filesystem path works.
- **iOS**: Copy to the Documents directory at runtime, or download in-app.

### Android

Models can be placed in:
- App's internal files directory: `context.filesDir`
- External storage (with permission)
- Downloaded at runtime

Example download:

```kotlin
val modelUrl = "https://huggingface.co/.../model.gguf"
val destFile = File(context.filesDir, "models/model.gguf")

// Use your preferred download method (OkHttp, URLConnection, etc.)
```

## Troubleshooting

### iOS/macOS

| Error | Solution |
|-------|----------|
| `No such module 'ForgeSwift'` | Clean build folder (⌘⇧K) and rebuild. |
| `llama.xcframework not found` | Check that `llama.xcframework` exists in the repo root. |
| `ForgeRustCore.xcframework not found` | Rebuild with `forge-rust/scripts/package-xcframework.sh` |
| `Undefined symbols` | Clean all build folders and rebuild from scratch. |

### Android

| Error | Solution |
|-------|----------|
| `NDK not configured` | Install NDK 27.0+ via SDK Manager. |
| `CMake not found` | Install CMake 3.22.1 via SDK Manager. |
| `libforge_core.so not found` | Run `./forge-rust/scripts/build-android.sh` |
| `UnsatisfiedLinkError` | Check that native libs are in `jniLibs/{abi}/` |

### Runtime Errors (Both Platforms)

| Error | Solution |
|-------|----------|
| `ModelLoadFailed` | Verify the model path is correct and file exists. |
| `MultimodalLoadFailed` | Check the CLIP/mmproj path for vision models. |
| `Out of memory` | Use smaller quantized model (Q4_K_M) or reduce context. |
